# Camp Structure Detection — Mask R-CNN Baseline

Instance segmentation of refugee camp structures in drone/satellite imagery using Mask R-CNN.

## Quick Start

### Prerequisites
```bash
conda activate camp_maskrcnn
# torch 2.14, torchvision 0.29
```

### Typical workflow

#### 1. Prepare data (one-time)
```bash
# Clean raw labels. reprject, clip to AOI, fix geoms, class filtering(if poss), flag dupes.
python -m scripts.clean_labels
# Output: cleaned.geojson

# Build dataset: merge imagery, rasterize labels, create tiles
#  Input: cleaned.geojson, AOI, images,
python -m scripts.build_dataset
# Output: dataset_camps/ with index.geojson, images/, masks/
```

#### 2. Quality check (one-time, before first training)
```bash
# Detect suspicious tiles (density mismatches, unlabeled bright blobs)
python -m scripts.tile_check
# Output: qa_candidates.geojson, qa_ranked.csv, qa_top24.png
# → Review in QGIS, fix labels in labels_clean/ if needed, rebuild dataset
```

#### 3. Train & evaluate
```bash
# Train a single model
python -m scripts.train_maskrcnn \
  --run 5b \
  --backbone-layers 3 \
  --aug full \
  --min-area 25 \
  --train-frac 1.0
```
Output: bestloss.pt, final.pt, checkpoint.pt (for resumes) 
```bash
# Evaluate on val (default) or test
python -m scripts.eval_maskrcnn \
  --run 5b \
  --ckpt checkpoints/5b_bestloss.pt \
  --split val
```
Eval Output: contact_sheet


#### 4. Batch runs (optional)
```bash
# Queue multiple training jobs
./scripts/queue_runs.sh
```

## Script reference

| Script | Purpose | Input | Output |
|--------|---------|-------|--------|
| `clean_labels.py` | Remove duplicates, bridges from raw labels | `labels_raw/` | `labels_clean/cleaned.geojson` |
| `build_dataset.py` | Tile imagery and labels | `labels_clean/`, `data/kutupalong/` | `dataset_camps/index.geojson`, `images/`, `masks/` |
| `tile_check.py` | Flag suspicious tiles for QA | `dataset_camps/index.geojson`, images, masks | `qa_candidates.geojson`, `qa_ranked.csv`, `qa_top24.png` |
| `train_maskrcnn.py` | Train Mask R-CNN | `dataset_camps/` | `checkpoints/{run}_*.pt` |
| `eval_maskrcnn.py` | Evaluate on val/test | `dataset_camps/`, `checkpoints/` | Metrics, contact sheets |
| `augcheck.py` | Inspect augmentations | `dataset_camps/` | — (vis in notebook) |
| `audit_labels.py` | Audit label geometry | `dataset_camps/index.geojson`, masks | Stats, HTML report |
| `slivers.py` | Find small/thin structures | `dataset_camps/index.geojson` | List of slivers |

## Directory structure

```
dataset_camps/
  ├── index.geojson       # Canonical tile registry (geometries, splits, stats)
  ├── images/             # 512×512 RGB tiles (0.1 m/px native)
  ├── masks/              # 512×512 binary rasterized labels
  ├── qa_candidates.geojson   # QA flagged tiles (transient; regenerated by tile_check.py)
  └── qa_ranked.csv       # Ranked list of QA flags
checkpoints/
  └── {run}_*.pt         # Model checkpoints (per epoch + best loss)
logs/
  └── {run}_stdout.log   # Training logs
```

## Current state
- **Run 5b** (latest): val AP .50:.95 = 0.315, test AP = 0.311
- Data: 721 tiles (482 train / 108 val / 131 test) from 3 camps, 0.1 m/px drone imagery
- Labels: ~19,307 structures from UNOSAT/REACH Jan 2019 footprints (cleaned)

## Key parameters

**Training** (`train_maskrcnn.py`):
- `--backbone-layers`: trainable ResNet layers (default 3)
- `--aug`: augmentation mode (flip, rot90, brightness/contrast) (default "flip")
- `--min-area`: min instance size in pixels to keep during training (default 4)
- `--train-frac`: fraction of training split to use (default 1.0, for learning curves use 0.25/0.5)

**Evaluation** (`eval_maskrcnn.py`):
- `--split`: val or test (default val)
- `--ckpt`: checkpoint path (default best loss)
- `--run`: run name (default 5b)

## Notes

- Do **not** re-evaluate test split repeatedly; it should be checked once at the end to avoid
  turning it into a second validation set.
- The gap between val and test metrics (AP 0.315 vs 0.311) is minimal; no sign of overfitting.
- Residual label noise (~5 months imagery/label drift) is acceptable for training; only clean
  val labels if model disagreements reveal genuine errors.
